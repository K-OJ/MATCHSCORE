# Sprint Plan sprint1

## 기간
2026-06-11 ~ 2026-06-18 (7일, 1주 스프린트)

## 목표
MatchScore MVP 전체 기능을 1회 스프린트로 완성한다. 방 생성/입장, 참가자 등록(이름 기반), 경기별 스코어 예측 입력, 보드 화면(참가자별 예측 테이블 + 총 상금), 결과 입력 및 자동 정산(우승자 판정, 이월 로직)을 포함한다.

## ROADMAP 연계 기능
- F1: 방 생성/입장 (6자리 코드 시스템)
- F2: 참가자 등록 (이름 기반 식별, 재접속 지원)
- F3: 베팅 설정 (방장이 인당 금액 설정, 총 상금 자동 계산)
- F4: 경기 목록 (대한민국 2026 월드컵 조별리그 3경기 + 토너먼트)
- F5: 스코어 예측 입력
- F6: 보드 화면 (참가자별 예측 스코어 테이블, 총 상금 표시)
- F7: 결과 입력 및 자동 정산 (정확 스코어 독식, N분의 1, 이월 로직)

## 작업 목록

### 인프라/기타
- ✅ T1: `docker-compose.yml` 작성 -- backend / frontend / SQLite(볼륨 마운트) 서비스 정의, `app/backend/Dockerfile` 및 `app/frontend/Dockerfile` 빌드 컨텍스트 연결 (2h)
- ✅ T2: 프로젝트 기본 구조 세팅 -- FastAPI 앱 초기화(`app/backend/main.py`, 라우터 구조), React 앱 초기화(`app/frontend/` Vite + React + Tailwind CSS), 의존성 파일 작성 (3h)

### 백엔드
- ✅ T3: DB 모델 및 스키마 정의 -- SQLite + SQLAlchemy 모델(Room, Participant, Match, Prediction, Result), DB 초기화 로직, Pydantic 스키마 (3h) [DB 스키마 생성] [새 의존성: sqlalchemy, aiosqlite]
- ✅ T4: 방 API 구현 -- `POST /api/v1/rooms` (방 생성, 6자리 코드 자동 생성, 베팅 금액 설정), `GET /api/v1/rooms/{code}` (방 정보 조회), `POST /api/v1/rooms/{code}/join` (참가자 등록, 이름 중복 시 동일 참가자로 인식) (3h)
- ✅ T5: 경기 데이터 API -- `GET /api/v1/rooms/{code}/matches` (경기 목록 반환), 경기 초기 데이터 시딩 로직 (대한민국 조별리그 3경기 고정값 + 토너먼트 경기 방장 추가 기능) (2h)
- ✅ T6: 예측 API -- `POST /api/v1/rooms/{code}/predictions` (스코어 예측 입력/수정), `GET /api/v1/rooms/{code}/predictions` (전체 예측 현황 조회) (2h)
- ✅ T7: 결과 입력 및 정산 API -- `POST /api/v1/rooms/{code}/matches/{id}/result` (실제 스코어 입력, 방장만), 자동 정산 로직(정확 맞춤 독식 / 다수 맞춤 N분의1 / 미적중 이월), `GET /api/v1/rooms/{code}/standings` (정산 현황) (4h)
- ✅ T8: 백엔드 테스트 작성 -- 방 CRUD, 참가자 등록, 예측 입력, 정산 로직 단위/통합 테스트 (3h)

### 프론트엔드
- ✅ T9: 메인 페이지 및 방 입장 UI -- 방 생성 폼(베팅 금액 입력), 방 코드 입력 폼, 이름 입력 폼, 모바일 반응형 (3h)
- ✅ T10: 보드 화면 UI -- 경기 목록 탭/카드, 참가자별 예측 스코어 테이블, 총 상금 표시 영역, 정산 결과 표시, 모바일 반응형 (4h)
- ✅ T11: 스코어 예측 입력 UI -- 경기별 스코어 입력 폼(홈/어웨이 점수), 예측 제출/수정 기능 (2h)
- ✅ T12: 방장 관리 UI -- 실제 경기 결과 입력 폼, 토너먼트 경기 추가 기능, 정산 트리거 (2h)
- ✅ T13: API 클라이언트 레이어 -- `app/frontend/src/api/` 디렉토리에 Axios/fetch 추상화, 타입 정의 (2h)
